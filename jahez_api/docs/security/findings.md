# Security and Correctness Findings

Register of findings from security reviews, with how each was proven, fixed and guarded. New reviews append rows; rows are never deleted. Phase 3 code-review findings CR-1 to CR-10 are in the [Phase 3 log](../phases/phase-03-auth.md#5-code-review-findings).

**Evidence levels:** *Reproduced*: a test or command showed the defect on the real code before the fix. *Statically confirmed*: shown by reading the code or the framework source, without a running reproduction. **Status:** *Fixed* (regression test in place), *Mitigated* (risk reduced; residual risk stated), *Accepted* (no change, with a reason).

## Phase 9 `finecomb` audit (2026-10-03)

Scope: `app/`, `bootstrap/app.php`, `config/`, `routes/`, `database/migrations/`, `database/seeders/`, `phpstan.neon`, `.env.example`, `postman/`. Excluded: `vendor/`, `node_modules/`, `storage/`, `.claude/`. Method and coverage: [Phase 9 log](../phases/phase-09-hardening.md#3-finecomb-audit).

| FC-01 | **Login lockout bypass by respelling the email.** The `utf8mb4_unicode_ci` column collation treats `mem\u{FE0F}ber@…` (a variation selector, which the `email` rule accepts) as `member@…`, but the throttle keys used the transliterated spelling (`mem?ber@…`). | FC-03 | **Audit-log cursor crafted by the client caused a 500** (missing or null `id`, missing direction, a bare number). | FC-06 | **A non-bcrypt `HASH_DRIVER` breaks login timing protection.** With `argon2id`, an unknown email failed with 500 while a known one got 422, which reveals accounts. | FC-09 | **`GET /` writes a session row for every visitor without a cookie** when `SESSION_DRIVER=database` (the default). | FC-10 | `app:create-admin` wrote the account and its audit entry outside a transaction | Low | Reproduced (forced audit failure) | Fixed | One transaction | `CreateAdminUserTest` › creates no administrator when the audit entry cannot be written |
| FC-11 | `AuditLog::record()` accepted any model; an unmapped subject failed with "Undefined array key" | Low (maintainability) | Statically confirmed | Fixed | Parameter typed `User\|Factory\|ServiceProvider\|null`, checked by Larastan | Larastan level 8 |
